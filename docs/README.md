# Documentation

- `system-overview.md` — what the ball is, the boards, how the
  image reaches the surface, and power
- `design-grape-fpc.md` — the Grape FPC design: Goldberg layout,
  gore shape, cassette system, why it is not a shield, and
  manufacturing
- `assembly.md` — how the stack goes together (core, batteries,
  mother-ring, power-AB, Goldberg panels), with the order and the
  checks at each step
- `usage.md` — power on/off by magnet, video upload from an iPhone,
  gesture controls (triple-shake menu), charging
- `measurements.md` — measured data behind the published figures
  (discharge test: 10 h 9 min at 50% brightness, max 30.9 °C),
  each figure with its test conditions, and an explicit list of
  what has not been measured yet
